# ADR 0001：本地优先与主题无关

**状态：Accepted**  
**日期：2026-09-11**

## 背景

Hexo 用户通常已经拥有本地站点、Markdown 文件、图片资源和 Git 仓库。为了改善写作体验而引入数据库、账号系统或远程图片服务，会增加成本和迁移风险，也偏离了项目最初的低维护目标。

## 决策

Hexo Workbench 采用本地优先模型：

- 文章和图片始终写入用户工作区；
- Git 继续作为版本记录和同步方式；
- 不要求 Hexo Workbench 账号或自建后端；
- 不绑定 Tessera 或其他 Hexo 主题；
- 远程图片上传、在线 CMS 不属于 MVP；Git 管理和生产部署/发布明确不属于产品功能，由已有工具和 hook 负责。

## 影响

优点：

- 几乎没有额外服务成本；
- 内容可迁移、可备份、可直接用其他编辑器打开；
- 插件离线时文章仍然可用；
- 实现范围集中在真正的写作摩擦上。

代价：

- 手机和浏览器端编辑不是第一阶段目标；
- 用户需要自己维护 Git 和 Hexo 环境；
- 多人协作权限需要交给 Git 平台处理。

## 重新评估条件

跨设备写作、多人协作或在线审核只有在产品范围被明确重新批准时才评估；不因编辑功能扩展而默认加入 Git 或发布功能。
